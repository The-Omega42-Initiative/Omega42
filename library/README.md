# The Library: the archive collection

Documents from the Originator's archive (Google Drive and OneDrive), published as HISTORICAL Library editions on the Originator's instruction of 20 November 2026, under the archive policy (docs/ARCHIVE_POLICY.md, Decision 3.4). The current release, V335 Rev.451, governs wherever an edition differs from it.

Every edition carries:
1. a banner and a field table: title, date, authorship as stated, source drive, class;
2. a name check: no personal name, place or address; personal, biographical, lottery and prediction material is withheld;
3. a recomputation of every arithmetic and geometric statement (`python3 records/library/recompute_lib01.py`, run in CI), each marked holds, restated, does not hold, or no derivation;
4. a concordance: where each idea now lives in the Core and the Companion;
5. the text as written, with formatting cleaned, or a summary where a fuller version of the same document is published.

The originals are not edited. No file identifiers or links to the drives are kept here.
