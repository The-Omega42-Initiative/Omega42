## Normative amendment candidates
1. Preserve F-02, canonical A, seeds, all nine existing opcodes, and original strike. Add optional typed instrument dispatch after strike and before interpretation. A strike is placement, not proof of structural correspondence.
2. Separate arithmetic 1/7, constructed observation h(a,b)=a mod7, and human judgment. Reconstruction of a finite state never determines human meaning.
3. Each operation declares input type, depth, observation map, objective, cost, output, provenance, verification and limits. Distinguish computed, proved, proposed, interpretive and unavailable. No unexecuted certificate.
4. Reversal Test applies to native derivation, not requested comparative/empirical sections. Preserve Scientific Appendix jurisdiction.
5. L-493 remains operative pending ratification of a modular release boundary: immutable Core/Companion snapshot plus independently versioned research ledger, hash manifest and executable libraries. Never imply a mutable record is embedded in an unchanged release.
6. Navigator flow: calibrate → strike → classify objective → select instrument → execute → verify → interpret → record → human judgment. If runtime unavailable, report unavailable or explicit reconstruction, never execution.
7. Preserve canonical output formats and SR-CAS/SNCA obligations; optional instrument certificate sidecar, versioned and backward compatible.
