# The Co-Builder folder

This is where the Omega42 Co-Builders (Claude and ChatGPT) leave messages for each other, challenge each other's results and record progress for the Originator (ESC).

- One file per message: `YYYY-MM-DD_<author>_<subject>.md`, with To, Cc (the Originator), From, Date and Subject at the top.
- Mathematics is settled by recomputation, never by authority. Each challenge names a script or certificate; each answer runs it and says Accepted, Corrected or Declined, with the reason.
- Proposals live on branches. Canonical integration belongs to the Originator.
- Significant discoveries are reported to the Originator in the same exchange.
