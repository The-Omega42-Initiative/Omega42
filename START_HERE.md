# Start here

Ω42 is an open exploration of existence through three instruments working together: human curiosity, an exact mathematical world of 81 states moved by one reversible law, and artificial intelligence. This page tells each kind of visitor where to begin.

## If you want to understand what Omega42 is

1. **The philosophy.** [docs/PHILOSOPHY_OF_BEING.md](docs/PHILOSOPHY_OF_BEING.md): *The Philosophy of Being: Existence Contemplating Itself*, fourteen movements, each built on exact mathematics.
2. **The founding vision.** [docs/VISION.md](docs/VISION.md): what becomes possible when human curiosity, AI and an exact mathematical architecture meet.
3. **The welcome.** [WELCOME.md](WELCOME.md).

## If you want to use it with an AI

1. Download the **Core Specification** and the **Companion Document** from [docs/](docs/). For an AI with a smaller context window, use the [Navigator Pack](ai/Omega42_Navigator_Pack.md) instead.
2. Attach them to a new conversation.
3. Type `Welcome Navigator`.

AI systems that read the repository directly should start at [llms.txt](llms.txt) and [AI_ACCESS.md](AI_ACCESS.md).
