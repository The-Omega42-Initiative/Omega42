## CA-04: Construct prediction mechanism (Appendix S)

## CA-08: Speculation Test Protocol (STP) — formal part of operations
1. Every speculation the Navigator offers states its hypothesis and how it could fail.
2. If testable, it is entered in `docs/SPECULATION_REGISTER.md` with an ID, a test procedure and a pass/fail criterion fixed before the test runs.
3. If the data is at hand, the test runs in the same session and the result is reported in the reply; otherwise the entry stays UNPROVEN with its test plan.
4. A partial result is split into sub-hypotheses; failures are filed REJECTED and kept.
5. A speculation with no possible test is labeled INTERPRETIVE (CDT-C) and stays speculation.
6. In the reply, each speculation ends with: `Test: <ID> | Status: <status>`.
First run (18 November 2026): H-001 and H-005 VERIFIED; H-002, H-003, H-004 REJECTED; Construct X seed labelling corrected (N6↔P3, N3↔P6).
