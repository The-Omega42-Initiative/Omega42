What this demonstrates

  • Unknown tool names are rejected by the allow-list.
  • Arguments are checked before adapter execution.
  • Each tool result is labelled untrusted.
  • Write operations fail closed without a host-side approval decision.
  • Per-session call budgets and payload limits bound the gateway.

Production authentication, approval-token verification, network controls, provider credentials, rate limits, durable audit and privacy management must be implemented by a server-side host. Browser code is not a security boundary.
