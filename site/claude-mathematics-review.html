For 0 ≤ j < k, the shell probability is (8/9)·9−j; the zero vector has probability 9^(-k). Every unit norm modulo 3^m has exactly 4·3^(m−1) primitive preimages. Conditional on shell j, reduced unit norms and the corresponding norm-square orbit labels are uniform. Each shell has 3^(k−j−1) equal-sized Fibonacci orbits. In the inverse limit, the same shell law holds for Haar measure on Z₃².

This is an exact counting/Haar-measure statement, not a physical, psychological, or consciousness probability law. The finite-level test has been committed but its CI outcome is not verified.
